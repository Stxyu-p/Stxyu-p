## Engineering Principles

- **Local-first & zero-telemetry** — data stays on the machine; no hidden network calls.
- **Dependencies as a budget** — stdlib and native platform features before any third-party package.
- **Governance over hope** — invariants enforced in code and schema, not conventions.
- **Prove it by running it** — every claim backed by a test suite or a real execution log.
